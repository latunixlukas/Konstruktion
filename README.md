# Werkstatt-Zeichenbrett

Einfaches Konstruktions-Werkzeug im Browser für Schlosser- und Metallbau-Azubis.

- Rechtecke (Bleche, Flachstahl, Laschen) mit Dicke und Werkstoff
- Bohrungen: Durchgangsbohrungen nach ISO 273 oder Gewinde mit Kernloch
- Schrauben, Muttern, Scheiben (ISO 4017, ISO 4762, ISO 4032, ISO 7089) von oben oder von der Seite
- Linien, Mittellinien und Maße
- Umschaltbar zwischen 2D (Zeichnen) und 3D (Ansehen, Drehen, Zoomen)
- Einheiten mm / cm / m umschaltbar, Eingaben wie `25cm` oder `0,3m` möglich
- Automatische Stückliste mit Masse (kg), Schriftfeld, Export als PNG/SVG, Speichern als Datei

## Benutzen

`index.html` einfach im Browser öffnen – keine Installation nötig.
Für alle Azubis online: in GitHub unter *Settings → Pages* den Branch auswählen, dann ist die Seite unter
`https://<benutzer>.github.io/Konstruktion/` erreichbar.
